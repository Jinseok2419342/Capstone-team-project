## 1. 작품의 개요

Re:Found는 Raspberry Pi와 카메라로 보관 구역의 물품 변화를 감지하고, 외부 멀티모달 AI로 물품의 이름과 분류를 추론하는 분실물 관리 시스템이다. 등록·이동·제거 기록을 관리자 웹의 보관 현황과 연결한다.

학교·도서관 등의 실내 보관대를 활용 대상으로 하며, 관리자가 사진·기한·처리 이력을 한곳에서 확인하도록 설계하였다. 불확실한 AI 결과는 확인 필요 상태로 남겨 관리자가 검토한다.

## 2. 작품의 구성 및 동작 설명

• 감지: 움직임이 멈춘 뒤 장면을 비교하고, 기존 물품과 대응하여 등록·이동·제거를 판단한다.

• 추론: 새 물품과 모호한 제거에만 전후 증거를 전송한다. 명확한 이동·제거는 로컬에서 처리한다.

• 관리: 물품 정보 확인·수정, 기한 연장, 회수·폐기·복원과 활동 이력을 웹에서 관리한다.

권기원 — 개발·시연 지원 / 자료 검토·교정, 시연 준비·운영

## 4. 핵심기술 설명

### 가. 장면 변화 기반 물품 감지와 이동 추적

OpenCV로 장면 정합과 조명 보정을 수행하고, 움직임 종료·안정화를 확인한 뒤 변화 영역을 찾는다. 기존 물품의 위치와 대응해 같은 물품의 이동을 새 등록과 구분한다.

물품 기록이 DB에 반영된 것을 확인한 뒤 기준 장면을 갱신하며, 반영에 실패한 사건은 재시도한다. 화면에서 사라짐을 나타내는 회수 상태는 실제 소유자 반환 여부와 구분한다.

### 나. 전후 증거를 활용한 선택적 멀티모달 추론

새 물품이나 모호한 제거가 발생하면 전체 장면 전후와 변화 영역 확대 전후의 이미지를 최대 4장 전송한다. AI의 의미 해석을 로컬 감지 결과와 결합하며, 모든 프레임을 외부 API로 보내지 않는다.

AI 응답 전에 관찰 기록을 먼저 저장한다. 응답 오류·낮은 신뢰도는 확인 필요로 보존하고, 늦게 도착한 응답이 관리자 수정이나 이후 물품 이동과 충돌하지 않도록 적용 조건을 검사한다.

### 다. 관리자 웹과 물품 생명주기 관리

그림. 실제 Pi 관리자 대시보드 삽입 위치 — 화면 캡처 후 교체

FastAPI·SQLite 기반으로 물품 검색, 보관 기한, 검토 상태, 회수·폐기·복원과 활동 이력을 연결한다. 웹 알림과 SMTP 메일 발송을 구현했으며, 관리자는 이름·분류·기한을 수정할 수 있다.

기본 실물 등록·이동·회수와 웹·OpenAI 동작은 사용자 확인 기록이 있다. 정량 인식 성능, 실제 메일 수신 및 장시간 운영 검증은 후속 과제로 남아 있다.
