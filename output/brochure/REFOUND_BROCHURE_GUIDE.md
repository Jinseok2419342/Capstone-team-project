## 실제 Pi 화면 캡처 방법

1. [Windows 핫스팟 안내](../../REFOUND_WINDOWS_HOTSPOT_GUIDE.md)대로 접속해 노트북에서 `http://127.0.0.1:18000`을 엽니다.
2. **실제 카메라로 물품 하나를 등록**합니다. 물품을 놓고 손을 뺀 뒤 AI 분석 완료 또는 확인 필요 상태를 그대로 확인합니다. 촬영을 위해 기존 기록을 초기화할 필요는 없습니다.
3. 대시보드에서 **실시간 카메라 영상, 보관 현황, 확인 필요/기한 영역**이 함께 보이도록 브라우저 크기나 배율을 조절합니다. 가능하면 브라우저 폭을 1280px 이상으로 둡니다.
4. `Win + Shift + S`로 필요한 화면을 잘라 PNG로 저장합니다. 주소창·API 키·개인 메일·얼굴·이름표 등이 보이면 캡처 영역에서 제외합니다.
5. 가로 약 **16.8cm**, 세로 **5.7cm**인 현재 칸에 맞게 핵심 영역을 넓게 잘라 넣습니다. 전체 화면 글자가 너무 작으면 카메라와 보관 현황 중심으로 자르세요. 사진을 가로·세로로 따로 늘려 찌그러뜨리지 않습니다.
6. 캡처 아래 임시 문구를 다음처럼 교체합니다: **`그림. 실제 Pi 관리자 화면 — 2026-00-00 촬영`**. 날짜는 실제 촬영일로 바꿉니다.

저장소의 개발 검사 PNG는 합성 카메라·임시 DB 화면이므로 실제 Pi 캡처 대신 넣지 않았습니다. 화면에 나타난 물품 수나 확신도는 정량 정확도 결과로 설명하지 않습니다.

## 한글에서 사진 넣기

가장 단순한 방법은 **회색 안내 그림만 선택해 삭제 → 그 위치에 새 그림 삽입**입니다.

1. 이름·표 테두리가 아니라 ‘사진 삽입’ 안내 그림을 한 번 클릭합니다. 그림 테두리에 선택점이 나타났는지 확인하고 `Delete`를 누릅니다.
2. 커서를 같은 위치에 두고 **입력 → 그림 → 그림**에서 준비한 파일을 선택합니다. [한컴 공식 그림 삽입 도움말](https://help.hancom.com/hoffice/multi/ko_kr/hwp/insert/figure/figure%28figure%29.htm)
3. 그림의 **개체 속성**에서 ‘글자처럼 취급’을 적용하고 원본 비율을 유지하며 위 표의 크기에 맞춥니다. 이름과 역할 문장은 그대로 둡니다.
4. 2쪽 대시보드도 같은 방법으로 안내 그림만 교체하고, 아래 임시 캡션도 실제 촬영일로 바꿉니다.
5. 다른 이름으로 저장한 뒤 인쇄 미리보기에서 **총 2쪽**, 사진과 글의 잘림, 3쪽으로 넘어간 내용이 없는지 확인합니다.
