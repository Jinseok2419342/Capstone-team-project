재부팅 명령은 `sudo reboot`, 종료는 `sudo shutdown -h now`입니다. 활성 AI 작업이 있다면 끝난 뒤 실행합니다. 재부팅 시 SSH 터널은 끊기므로 [시작 가이드 5절](FRESH_SD_START.md#5-가장-먼저-앱-열기--tailscale-없이-가능)의 명령을 다시 실행합니다.
