# 최종보고 시연 준비 — 10/27 연습, 11/03 발표

[시작 안내](../../START_HERE.md) · [최종보고 정리](FINAL_REPORT_PLAN.md) · [핫스팟 실행·종료 상세](../guides/WINDOWS_HOTSPOT_GUIDE.md)

발표 슬라이드는 학교 가기 전에 끝내 두고, 학교에서는 **이 문서 하나로 시연만** 준비한다. 형식이 요구하는 것: 시연 순서와 핵심 기능 소개(4.1), **현장에서 새 입력값으로 처음부터 끝까지 연속 시연**, 정상·제한 기능 구분(4.2), 오류 대비 녹화영상. 숫자는 10/25 실험 결과([결과 문서](../paper/RESULTS_2026-10-25.md))로 채웠다. 발표 슬라이드는 [Re:Found 최종보고 덱](https://claude.ai/artifact/DsBPmugyoDJ7YLKdYD5G9B)(원본 `final/deck/`).

## 1. 챙길 것

- [ ] Pi(카메라 케이블 연결 확인)와 카메라 스탠드, 흰 보관판(또는 흰 종이), 테이프
- [ ] Pi 전원: 어댑터(강의실 콘센트 위치 확인) 또는 **완충한** 보조배터리
- [ ] 노트북과 충전기, 프로젝터 연결 젠더(HDMI 또는 USB-C)
- [ ] 시연 물품 3개: 10/25 실험에서 잘 인식된 **리모컨 · 지갑 · 음료 팩**(시연은 준비한 물건으로만 한다 — 발표 환경상 청중 물건은 빌리지 않음, 10/26 사용자 결정). **줄이어폰처럼 얇은 물건, 눕힌 머그컵처럼 구르는 물건은 피한다**(실험에서 실패).
- [ ] **백업 영상이 없다면 만든다**: 10/25에는 리허설 녹화를 하지 않았다(도우미를 리허설 없이 다시 시작). 10/27 연습 때 아래 대본대로 한 번 하면서 Win+Alt+R로 녹화해 두면 된다
- [ ] **백업 영상**: 10/25 리허설 녹화(노트북 `동영상\캡처` 폴더)를 바탕화면에 `시연백업.mp4`로 복사

## 2. 발표 30분 전 — 설치와 연결

1. 보관판을 책상에 놓고 스탠드를 테이프로 고정한다. 카메라에 보관판 전체가 들어오게 하고, **창가 햇빛이나 프로젝터 빛이 보관판에 바로 닿지 않는 자리**를 고른다.
2. 이후는 평소 순서 그대로다: 노트북을 학교 Wi-Fi에 연결 → `ReFoundLaptop` 핫스팟 켜기 → Pi 전원 연결 → 2~3분 기다리기 → 노트북 새 PowerShell에서 아래 명령 → Pi 비밀번호 입력(이 창은 끝까지 열어 둠) → 브라우저에서 `http://127.0.0.1:18000`.

   ```powershell
   ssh -o ExitOnForwardFailure=yes -L 18000:127.0.0.1:8000 refound@refound-pi.local
   ```

3. 대시보드의 실시간 카메라에 보관판이 보이면 연결 완료.

## 3. 1분 점검, 그리고 초기화

1. 점검용 물건 하나를 놓고 손을 뺀다 → 카드가 생기고 → AI 이름이 붙는지 본다.
2. 옆으로 옮긴다 → **새 카드가 생기지 않고** 같은 카드의 기록만 바뀌는지 본다.
3. 치운다 → 회수 처리되는지 본다.
4. 보관판을 비우고 대시보드의 **시연 초기화 → 백업 없이 초기화**. 화면이 빈 상태로 시연을 시작한다.

AI 이름이 1분 넘게 안 붙으면 노트북의 학교 Wi-Fi 인터넷부터 확인한다.

## 4. 내 차례 직전 — 화면 정리

- 프로젝터: Win+P → **복제**.
- 브라우저: 다른 탭은 닫고, 대시보드 화면에서 **F11(전체 화면)**, 뒤에서도 보이게 **Ctrl + 키로 125–150% 확대**.
- 알림 끄기(Windows 방해 금지), 노트북은 충전기에 연결.
- SSH PowerShell 창은 **최소화만**(닫으면 연결이 끊긴다).
- 백업 영상을 열어 첫 장면에서 멈춰 둔다.

- **정상 동작**: 한 번에 한 물건 놓기·옮기기·치우기, AI 이름·분류·기한, 관리 기능. **제한적**(10/25 실험에서 실제로 틀린 조건): 얇은 물건(줄이어폰 0/10), 굴러서 모양이 바뀌는 물건 옮기기(눕힌 머그컵 2/10), 화각 가장자리에 걸친 물건, 인터넷이 끊겼을 때(기록은 남고 이름은 ‘확인 필요’).
- 기다리는 시간에는 말을 멈추지 않는다. 치운 뒤 회수까지는 AI 재확인 때문에 등록보다 길 수 있다(실험에서 따로 재지는 않았다).

## 6. 막혔을 때 — 30초 안에 판단

| 증상 | 바로 할 일 |
|---|---|
| `Could not resolve hostname` | 설정 → 네트워크 및 인터넷 → 모바일 핫스팟 → 연결된 장치에서 Pi IP를 보고, 명령의 `@` 뒤만 그 IP로 바꿔 다시 실행 |
| 브라우저가 연결 안 됨 | SSH 창이 닫혔는지 확인 → 명령을 다시 실행 |
| 영상이 멈춤 | 브라우저 F5 |
| 손을 뺐는데 10초 넘게 카드가 없음 | 몸이나 그림자가 화면에 걸쳤는지 보고, 물건을 치웠다가 다시 놓기 |
| ‘분석 중’에서 넘어가지 않음 | 인터넷 문제일 가능성이 크다. “AI가 실패해도 기록은 남습니다”를 보여 주는 장면으로 설명하고 다음 단계로 |
| 옮겼는데 새 카드가 생김 | 실험에서도 확인된 한계라고 한 문장으로 말하고(실험: 이동 90번 중 17번 실패, 대부분 구르는 머그컵), 잘못 생긴 카드는 ‘감지 제외’ |
| 위로 1분 안에 해결되지 않음 | **백업 영상 재생**: “같은 장비로 찍어 둔 영상으로 이어서 보여 드리겠습니다.” |

## 7. 끝나고

SSH 창(Pi)에서 `sudo shutdown -h now` → 초록 LED 점멸이 끝나면 Pi 전원 분리 → 핫스팟 끄기.
