## 0. 결론 먼저

1. **라즈베리파이에 새로 설치할 것은 없다.** 앱은 9월 22일 설치본 그대로이고(그 뒤 앱 코드 변경 없음), 자원 기록 스크립트도 그때 이미 들어갔다. 바뀐 것은 노트북에서 돌리는 실험 도우미뿐이다. 노트북 폴더를 최신으로 받고 Python만 있으면 된다.
2. **실험은 하루 한 번, 약 2시간 30분**이다. 직접 손을 쓰는 시간은 약 1시간 20분이고 마지막 1시간은 자리를 비운다(그 시간에 발표 그림을 생성하면 된다).
3. 그 한 번으로 **논문 표 4–8·그림 2·5·6**, **최종보고의 성능 평가·실제 화면·오류 사례·기능 점검표·1학기 목표 대비 달성도**, **시연 백업 영상**, 남아 있던 **전원 재인가·무선 자동 연결 시험**까지 함께 나온다. 논문과 발표가 같은 숫자를 쓴다.
4. 10월 27일 연습에 실제 숫자를 넣으려면 **10/25(일) 또는 10/26(월)에 실험**하는 것이 좋다. 못 하면 연습판은 ‘측정 예정’으로 두고 11/03 최종판에 넣는다.
5. 그림은 **글자 없는 그림만 GPT로**, 글자·숫자가 들어가는 도식·차트·표는 Claude가 직접 그린다(5절). 생성형 AI 이미지에는 한글이 깨져 들어가기 쉽기 때문이다.

**2.2에 쓸 내용(형식의 ‘프롬프트, RAG, 학습 데이터’에 답하는 순서):**

- 사용 기술: Python, OpenCV, Picamera2, FastAPI, SQLite(WAL), HTML/CSS/JavaScript, systemd, SSH 터널·Windows 핫스팟, 외부 API는 OpenAI 또는 Gemini(설정에서 선택).
- AI 모델: 사전학습된 시각언어모델(VLM)을 **추가 학습 없이** 사용. 자체 학습 데이터는 만들지 않았다 — 분실물 종류가 정해져 있지 않아 고정 클래스 학습이 맞지 않고, Pi 4 2GB에서는 로컬 모델을 감시와 함께 돌릴 수 없었다(9월 현황보고).
- 프롬프트 설계: 전체 장면 전·후 2장 + 후보 영역 확대 전·후 2장(최대 4장), “전체 장면으로 변화 방향을 먼저 보고 확대 사진으로 물건을 식별”, 손·그림자·흔들림은 물건이 아님, 확신이 없으면 `uncertain`, 추정 가격 10만 원 이상은 귀중품.
- 응답 형식: JSON 스키마 강제(이름·설명·분류·추정 가격·신뢰도), 응답 완료·형식 검사. 신뢰도 0.5 미만·오류·지연 시에도 관찰 기록은 지우지 않고 ‘확인 필요’로 남긴다.
- RAG: 쓰지 않는다. 판단에 필요한 것은 문서 지식이 아니라 눈앞의 전후 장면이기 때문이다(1학기 기획의 ‘RAG 관리자 챗봇’은 검토 단계에서 제외 — 6절).
- 호출 정책: 등록과 모호한 제거만 AI를 부르고, 이동·명확한 제거는 Pi가 처리한다(호출 비율은 실험값).

## 5. 생성형 AI 그림 만드는 법

**원칙.** GPT 같은 이미지 생성 모델은 분위기·장면·아이콘을 잘 그리지만 **한글 글자와 숫자는 깨지기 쉽다.** 그래서 이미지 생성 모델에는 글자 없는 그림만 맡기고, 글자를 붙이는 일과 구성도·흐름도·차트·표는 Claude가 슬라이드 안에서 직접 그린다(정확하고 나중에 고칠 수 있다). Claude가 그린 도식도 생성형 AI 활용 그림이므로 형식의 ‘생성형 AI 그림 다수’를 충분히 채운다. 생성한 그림 아래에는 작게 “생성형 AI 이미지”라고 표기하는 것을 권한다. 실제 장치·화면·장면은 실제 사진만 쓰고 AI로 꾸미지 않는다.

**받는 방법.** 같은 대화창에서 이어서 생성하면 화풍이 맞춰진다. 이미지 생성은 보통 가로 3:2 크기로 나오므로 ‘가로’로 요청하면 되고, 16:9 슬라이드에 맞게 자르는 것은 Claude가 한다. 그림에 글자가 섞여 나오면 “글자를 모두 지우고 다시”라고 요청한다. 파일 이름을 `img-01-cover.png`처럼 바꿔 채팅에 첨부하면 해당 장에 넣는다. 무인 1시간 동안 만들면 시간을 아낄 수 있다.

**공통 스타일 문구 — 모든 프롬프트 맨 앞에 붙인다.**

> 깔끔한 플랫 벡터 일러스트, 부드러운 그림자와 약간의 입체감, 배경은 아주 연한 회백색(#F7F9F9) 단색. 색은 짙은 남색 #12303F, 청록 #0F7C7C, 연한 민트 #DDF1EE, 강조용 산호색 #F28C6B만 사용. 둥근 선, 사람은 얼굴 이목구비 없는 단순한 형태, 실사 사진 느낌 금지. **이미지 안에 글자·숫자·한글·영문·로고·워터마크를 절대 넣지 말 것. 화면이나 종이 속 내용은 추상적인 막대와 블록으로만 표현.**
