3.2 잘 된 사례와 오류 사례

잘 된 것, 그리고 틀린 것.

잘 된 사례

놓은 물건: 음료수

“두유 팩” · 음식

→ 보관 1일 자동

놓은 물건: 리모컨

“리모컨” · 일반

→ 보관 60일 자동

오류 사례

눕힌 머그컵 옮기기 — 10번 중 8번 실패

구르며 위에서 본 모양이 바뀌어 ‘사라짐 + 새 물건’ 두 기록으로 나뉨 → ‘확인 필요’에 표시

줄이어폰 — 10번 모두 감지하지 못함

얇고 바닥과 색 대비가 작아 변화로 잡히지 않음

에어팟 · 충전기 — 일반과 귀중품 사이를 오감

실제로 비싼 물건일수록 기준이 애매 → 마지막 판단은 관리자

사진: 10/25 실험 중 실제 AI 입력과 카메라 화면 · 이 밖에 화각 가장자리에 걸친 이동 3회 실패

약 30초. 잘 된 사례 두 개는 짧게: “음료수를 놓으면 두유 팩, 음식, 보관 1일. 리모컨은 리모컨, 일반, 60일.” 오류 사례에 시간을 더 쓴다: “눕혀 둔 머그컵은 옮길 때 굴러서 모양이 바뀌어, 같은 물건이 아니라 사라지고 새로 생긴 것으로 처리됐습니다. 그래도 기록이 지워지지는 않고 ‘확인 필요’로 관리자에게 올라옵니다. 줄이어폰처럼 얇은 물건은 아직 못 잡습니다. 에어팟과 충전기는 일반과 귀중품 사이를 오갔는데, 실제로 비싼 물건이라 기준 자체가 애매합니다. 그래서 마지막 판단은 관리자가 합니다.”
