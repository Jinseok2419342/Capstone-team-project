프롬프트

사용 · 핵심

  • 전체 장면 → 무엇이 바뀌었나
    확대 사진 → 무엇인가
  • 손 · 그림자 · 빛 · 흔들림은
    물건이 아니다
  • 확실하지 않으면
    ‘uncertain’으로 답한다

RAG

사용 안 함

  • 필요한 건 문서 지식이 아니라
    눈앞의 전후 장면
  • 1학기 기획의 관리자 챗봇은
    검토 단계에서 제외

학습 데이터

없음

  • 이미 학습된 시각언어모델을
    추가 학습 없이 사용
  • 물건 종류가 정해져 있지 않아
    고정 분류 학습은 맞지 않음
  • Pi 4 2GB에서는 로컬 모델을
    감시와 함께 돌릴 수 없음

답 형식 고정

JSON 스키마로 이름 · 설명 · 분류 · 추정 가격 · 확신도만 받습니다.
추정 가격 10만 원 이상은 귀중품 · 확신이 낮거나 오류가 나도 기록은 지우지 않고 ‘확인 필요’로 남깁니다.

분류 기준: 음식 · 음료 → 음식 · 지갑 · 휴대전화 · 고가 전자기기 → 귀중품 · 그 밖 → 일반

10

약 25초. 형식이 묻는 세 가지에 바로 답한다. “AI는 새로 학습시키지 않았습니다. 대신 잘 묻는 데 집중했습니다. 프롬프트에 판단 순서와 금지 규칙을 적고, 답은 정해진 형식으로만 받습니다. RAG는 쓰지 않았습니다. 필요한 건 문서가 아니라 눈앞의 사진이기 때문입니다. 확신이 낮으면 지우지 않고 ‘확인 필요’로 남겨 관리자가 판단합니다.”
