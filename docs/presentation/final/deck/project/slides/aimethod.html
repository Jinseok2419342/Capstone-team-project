2.2 AI 활용 방법 — 실제로 적용한 것

잘 묻고, 정해진 틀로만 받습니다.

① 사진 4장에 이름표

전체 장면 전 · 후 + 확대 전 · 후
사진마다 ‘변화 전 / 후’를 표시

② 판단 순서 프롬프트

전체 장면으로 방향 → 확대로 식별
손 · 그림자 · 빛은 물건이 아님

③ JSON 스키마로 고정

이름 · 설명 · 분류 · 추정 가격 · 확신도
정해진 칸과 값만 받습니다

④ 답을 그대로 믿지 않기

확신도 0.5 미만 · 형식 오류 · 끊긴 응답
→ 지우지 않고 ‘확인 필요’로

⑤ 규칙으로 한 번 더

추정 가격 10만 원 이상 → 귀중품
분류에 맞춰 보관 기한 자동

⑥ 필요할 때, 최신 것만

새 물건 · 애매한 사라짐만 호출
그사이 상태가 바뀐 늦은 답은 적용 안 함

프롬프트 — 사용 (①② 핵심)

RAG — 사용 안 함
필요한 건 문서가 아닌 눈앞의 장면

학습 데이터 — 없음
이미 학습된 모델을 그대로 사용

모두 현재 코드에 적용된 방식 · 분류 기준: 음식 · 음료 → 음식, 지갑 · 고가 전자기기 → 귀중품, 그 밖 → 일반

10

약 25초. “AI는 새로 학습시키지 않았습니다. 대신 잘 묻고, 정해진 틀로만 받도록 만들었습니다. 사진 네 장에 ‘변화 전·후’ 이름표를 붙여 보내고, 프롬프트에는 판단 순서와 물건이 아닌 것을 적었습니다. 답은 JSON 스키마로 정해진 칸과 값만 받고, 확신도가 0.5보다 낮거나 형식이 틀리면 지우지 않고 ‘확인 필요’로 남깁니다. 추정 가격 10만 원 이상은 귀중품으로 한 번 더 보정하고, AI는 새 물건이나 사라짐이 애매할 때만 부릅니다. 늦게 온 답은 그사이 물건 상태가 바뀌었으면 적용하지 않습니다.” 형식이 묻는 RAG와 학습 데이터는 아래 줄로 답한다(둘 다 쓰지 않음).
