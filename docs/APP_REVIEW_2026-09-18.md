## 검증 결과

- 변경 전 Python: 136개 통과.
- 변경 후 `python -m unittest discover -s tests -q`: **175개 통과**.
- `node --test tests/frontend/app.test.cjs`: **10개 통과**.
- `python -m compileall -q app experiments tests`, `node --check static/app.js`: 통과.
- `/`, `/static/app.js`, `/static/styles.css`, `/static/favicon.svg`: ASGI 클라이언트에서 200 응답 확인.
- HTML ID 중복 없음, ARIA 대상 존재, 설정 탭 5개의 연결 검사 통과.
- 테스트 DB·이미지는 임시 디렉터리를 사용했다. 실제 운영 DB 초기화·메일 발송·외부 AI 호출·실제 카메라 실행은 수행하지 않았다.
- 이 세션의 Browser 연결 목록이 비어 있어 실제 브라우저 조작·시각 검증은 수행하지 못했다. Node 테스트는 지연 HTTP 응답과 간단한 DOM 대역으로 실제 화면 제어 코드를 실행한다.

## 운영 시 남는 경계

- privacy 설정 전에 이미 접수된 callback/VLM 작업은 계속 처리될 수 있다. 카메라 장치의 물리적 전원 차단 기능은 아니다.
- 네이티브 카메라 read가 영구 정지하면 안전하게 강제 중단할 수 없다. 이 경우 감시는 종료 대기 상태에 머물고 데이터 초기화는 수행하지 않는다.
- SMTP 접수 직후 프로세스가 종료되는 경우 발송 여부를 확정할 수 없어 재시도 중복이 가능하다. 이미 시작한 SMTP 발송도 회수할 수 없다.
- 화면의 일반 물품 목록 API는 기존 최근 500건 제한을 유지한다. 이번 수정으로 전체 통계와 카메라 활성 추적에서는 이 제한을 제거했다.
- 로컬 인증·사용자 권한 체계는 이번 작업에 추가하지 않았다. 실제 배포 환경과 접근 범위를 별도로 결정해야 한다.
- 자동화 검증은 현장 정확도·성능 결과가 아니다. Pi에서 추가→이동→제거, privacy 후 재시작, 네트워크 단절, 알림·초기화 흐름을 확인한 뒤 논문용 실험을 시작한다.
