# 논문 실험 진행 안내 — 하루, 약 2시간 반

[논문 안내로 돌아가기](README.md)

**2026-10-11 축소판.** 실험 진행 도우미(`run_experiment.py`)가 화면 결과 판정, 처리 속도·Pi 자원 기록, AI 호출 집계, 결과표 작성을 모두 자동으로 한다. 사용자는 **안내대로 물건을 놓고·옮기고·치운 뒤 Enter**만 누르면 된다. 이전의 큰 실험 계획은 Git 기록(커밋 `55d59a9`)에만 있다.

## 한눈에 보기

| 단계 | 사용자가 할 일 | 시간 |
|---|---|---|
| 0. 준비 | 물품 10종 준비, 카메라·책상 테이프 고정 | 전날 15분 |
| 1. 시작 | 평소대로 Pi·터널 켜기 → 도우미 실행 → 물품 이름 입력 → 초기화 | 5분 |
| 2. 실험 A | 안내대로 등록·이동·제거 60회, 매번 Enter | 40분 |
| 3. AI 이름 확인 | AI가 붙인 이름이 맞는지 20번 확인(대부분 Enter) | 3분 |
| 4. 실험 B | 손 20회, 조명 10회, 그림자 10회, 매번 Enter | 20분 |

| 6. 마무리 | Pi 비밀번호 한 번 입력, 사진·캡처 2–3장 | 5분 |

직접 적는 기록지, 데이터베이스 복사, 별도 기록 프로그램, 집계 명령은 **필요 없다**.

## 0. 전날 준비

- **물품 10종**: 귀중품 3(예: 지갑, 이어폰 케이스, 시계), 일반 5(예: 우산, 텀블러, 필통, 책, 모자), 음식 2(예: 과자 봉지, 음료 캔). 너무 작거나 바닥과 같은 색인 물건은 피한다. 10개를 겹치지 않게 놓을 수 있는 공간이 필요하다.
- **고정**: 실험 내내 카메라와 책상이 움직이지 않게 테이프로 고정한다. 조명 실험 외에는 조명을 바꾸지 않는다.
- **장비 메모**(논문 표 4, 휴대폰 메모로 충분): 카메라 높이·거리, 방열판·팬·케이스 여부, microSD 용량, 실험 날짜·장소, 설정 화면의 AI 모델 이름.

## 1. 시작 (5분)

1. 평소 순서([START_HERE](../../START_HERE.md) 1–7단계)로 Pi를 켜고 SSH 터널과 브라우저 화면을 연다.
2. 노트북에서 **새 PowerShell**을 열고 프로젝트 폴더에서 실행한다. Python만 있으면 되고 설치할 것은 없다.

   ```powershell
   python scripts\experiments\run_experiment.py
   ```

3. 화면 안내에 따라 진행한다.
   - 물품 10개를 `지갑/귀중품`처럼 한 줄씩 입력한다.
   - 보관대를 비우고 관리자 화면의 **시연 초기화**를 누른 뒤 Enter.
   - Pi 비밀번호를 물으면 입력한다(Pi 자원 기록 자동 시작). Pi 이름으로 접속이 안 되면 실행할 때 `--pi refound@192.168.137.xxx`처럼 현재 IP를 붙인다.

## 2. 실험 A — 등록·이동·제거 (60회)

화면에 `[3/100] 등록 · 텀블러 — 텀블러을(를) 빈자리에 놓고 손을 뺀 뒤 Enter`처럼 할 일이 나온다. 행동을 하고 **손을 뺀 뒤 Enter**를 누르면, 도우미가 시스템 반응을 기다렸다가 `→ 시스템 결과: 등록 · 맞음`처럼 보여 주고 자동으로 기록한다. 10개 등록 → 10개 이동 → 10개 제거를 2회 반복한다.

**결과가 다르면** 도우미가 무엇을 하면 되는지 알려 준다(예: “물품을 치웠다가 다시 놓아 주세요”, “잘못 생긴 카드는 감지 제외”). 상태를 맞춘 뒤 Enter를 누르면 다음으로 넘어간다. 이 정리 동작은 결과에 들어가지 않는다. 실수로 행동을 잘못했다면 Enter 대신 `s`를 눌러 건너뛴다.

## 3. AI 이름 확인 (3분)

실험 A가 끝나면 등록된 물품마다 `실제 '텀블러' → AI '스테인리스 텀블러' (일반). 이름 맞음? Enter=O`처럼 묻는다. 도우미가 먼저 추측해 두므로 맞으면 Enter, 다르면 `o` 또는 `x`를 누른다. 사람이 그 물건을 부를 만한 이름이면 O다. 분류(귀중품·일반·음식)는 처음 입력한 분류와 비교해 자동으로 채점한다. 등록된 물품 사진도 결과 폴더의 `images`에 저장된다.

## 4. 실험 B — 물품 변화 없음 (40회)

안내에 따라 물품 1–5번을 올려 둔 뒤, 손을 넣었다 빼기 20회, 조명 끄고 10초 뒤 켜기 10회, 옆에 서서 그림자 드리우기 10회를 한다. 매번 행동이 끝나면 Enter. 정답은 모두 ‘반응 없음’이다.

## 5. 실험 C — 무인 1시간

안내가 나오면 Enter를 누르고 자리를 비운다. 사람이 화면에 들어오지 않게만 하면 된다. 1시간 뒤 자동으로 끝난다.

## 6. 마무리 (5분)

1. 도우미가 Pi 자원 기록을 끝내고 가져오려고 비밀번호를 한 번 더 묻는다.
2. `끝났습니다. 결과표: paper-run-…\paper-results\paper_tables.md`가 나오면 완료다.
3. **사진·캡처**: 관리자 화면 캡처 1장(논문 그림 2), 실험 장면 사진 1장(그림 5). 판정 예(그림 6)는 `images` 폴더의 사진에서 고른다. 사람 얼굴이 나오지 않게 한다.
4. `paper-run-…` 폴더와 사진, 장비 메모를 Claude에게 주면 원고에 반영하고 결과에 맞게 요약·고찰·결론을 고친다.

**중간에 끊겼을 때**(노트북 절전, 터널 끊김 등): 터널을 다시 연 뒤 `python scripts\experiments\run_experiment.py --resume paper-run-…`로 실행하면 끝난 시도는 건너뛰고 이어서 진행한다.

## 이 실험 하루로 함께 채워지는 것

- **논문**: 표 5–8, 본문 숫자 대부분, 그림 2·5·6.
- **최종보고 PPT(10월 27일 연습, 11월 3일 발표)**: 실험 중 찍은 관리자 화면 캡처는 14·15쪽의 실제 Pi 화면으로, `paper_tables.md`의 정확도·AI 호출 비율·자원 값은 19쪽 정량 결과로 그대로 쓸 수 있다. 같은 숫자를 쓰므로 논문과 발표 내용이 어긋나지 않는다.
- **팀논문 발표(11월)**: 같은 원고와 표를 사용한다.

## 참고: 결과를 어떻게 계산하나

- **시스템 결과 판정**: Enter 후 관리자 화면의 활동 기록에 새로 생긴 카메라 사건으로 판정한다(새 물품 감지 → 등록, 이동 기록 → 이동, 회수 → 제거, 사라짐 확인 요청 → 확인 필요, 없음 → 반응 없음). 최소 6초, 사건이 없으면 18초(제거는 AI 재검증 때문에 30초)까지 기다린다.
- **정확도** = 맞은 시도 / 100(무변화는 ‘반응 없음’이 정답). Wilson 95% 신뢰구간을 함께 낸다.
- **정밀도·재현율·F1** = 표 5 혼동행렬에서 등록·이동·제거별로 계산. 무변화 시도에서 나온 사건은 그 사건의 오탐이다.
- **AI 호출 비율** = (등록 + 제거 검증) / 전체 감지 사건(무인 감시 제외), **AI 처리 시간** = 새 물품 감지 기록부터 분석 완료 기록까지(1초 단위).
- **자원** = Pi 1초 간격 기록(CPU·메모리·온도)과 상태 API(분석 프레임률·처리 시간)의 평균·최대.
- 전력, 8시간 이상 안정성, 다른 방법과의 비교, 장애 주입은 이번 범위에서 뺐다. 심사에서 요청하면 그때 추가한다.
