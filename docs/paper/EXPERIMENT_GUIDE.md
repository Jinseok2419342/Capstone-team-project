# 실험 안내 — 쉬운 버전 (2026-10-25 실험 완료)

[시작 안내](../../START_HERE.md) · [10/25 실험 결과](RESULTS_2026-10-25.md) · [시연 준비](../presentation/FINAL_DEMO_GUIDE.md)

> **10월 25일 실험은 끝났다.** 결과는 [10/25 실험 결과](RESULTS_2026-10-25.md)에 있고 발표와 논문은 그 숫자만 쓴다. 이 문서는 심사 대응 등으로 **다시 실험할 때만** 본다.
>
> **실제로 해 보니 알게 된 점(다시 할 때 반드시 반영):**
> 1. **도우미의 자동 판정은 그대로 쓰지 않는다.** 앞 시도의 늦은 AI 재확인과, 실패한 시도를 다시 놓는 동작이 다음 시도의 판정에 섞인다. 10/25에는 본 실험을 손으로 기록했다(물품 10개 × 10회, 회차마다 등록 → 이동 → 제거, 등록 실패 시 다시 놓고 진행·첫 시도만 집계). 다시 할 때도 손 기록을 기본으로 하고, 도우미는 시간·처리 속도 기록용으로만 쓴다.
> 2. **Windows에서 도우미가 Pi 비밀번호 단계에서 멈출 수 있다.** Ctrl+C 후 `--no-pi`를 붙여 이어 하면 된다(CPU·온도 기록만 빠짐). CPU·온도가 필요하면 Pi 창에서 `monitor_pi_resources.py`를 직접 켜고 끝에 `scp`로 가져온다.
> 3. 물건끼리 너무 붙이지 않는다. 굴러가는 물건(눕힌 머그컵)과 얇은 물건(줄이어폰)은 실패 원인이므로 따로 기록한다.

아래는 10/25에 쓴 원래 안내다. 한 번의 실험으로 논문 결과와 발표 숫자가 모두 나오도록 만든 순서이며, 약 2시간 30분이 걸린다.

## 1. 전날 준비

- **물품 10개**: 귀중품 3(지갑, 이어폰 케이스, 시계 등), 일반 5(우산, 텀블러, 필통, 책, 모자 등), 음식 2(과자 봉지, 음료 캔 등). 너무 작거나 책상과 같은 색인 물건은 피한다. **첫 번째로 입력할 물건은 눈에 잘 띄는 것**(예: 텀블러)으로 — 리허설에 쓴다.
- **테이프**로 카메라 스탠드와 보관판을 고정한다. 실험 중 조명은 ‘조명 시험’ 때만 바꾼다.
- **휴대폰**: 사진 1장, 동영상 1개를 찍는다.

## 2. 노트북에 필요한 것 — 두 가지뿐

평소처럼 PowerShell로 Pi에 접속하는 것은 그대로다. 여기에 두 가지만 있으면 된다. **Pi에는 아무것도 설치하지 않는다.**

1. **Python** — PowerShell에서 `python --version`을 입력해 `Python 3.10` 이상이 나오면 된다. 안 나오면 `winget install Python.Python.3.12`를 실행하고 PowerShell을 새로 연다. 추가로 설치할 패키지는 없다.
2. **최신 실험 도우미** — 아래 링크를 눌러 받은 zip의 압축을 푼다(GitHub에 로그인된 브라우저에서).
   [최신 코드 내려받기](https://github.com/Jinseok2419342/Capstone-team-project/archive/refs/heads/main.zip)

## 3. 당일 순서

**켜기 (5분)**

1. 평소 순서대로 켠다: 노트북 Wi-Fi → `ReFoundLaptop` 핫스팟 → **꺼져 있던 Pi에 전원(랜선 없이)** → 2~3분 대기 → PowerShell 창 ①에서 SSH 명령 → 브라우저 `http://127.0.0.1:18000`. (명령은 [시작 안내](../../START_HERE.md#확정한-시연-실행종료-순서)와 같다. 창 ①은 끝날 때까지 닫지 않는다.)
2. 압축을 푼 폴더를 열고, 위쪽 주소창에 `powershell`을 입력해 Enter → PowerShell 창 ②가 그 폴더에서 열린다.
3. 창 ②에 입력한다.

   ```powershell
   python scripts\experiments\run_experiment.py
   ```

화면을 반으로 나눠 **왼쪽에 브라우저, 오른쪽에 창 ②**를 두면 편하다(창을 화면 끝으로 끌거나 Win+←/→). 창 ①은 최소화한다.

**그다음은 창 ②의 안내를 따른다.** 순서만 미리 보면 이렇다.

| 순서 | 할 일 | 시간 |
|---|---|---|
| 물품 입력 | `텀블러/일반`처럼 10줄 | 2분 |
| 장비 질문 6개 | 아는 것만 짧게, 모르면 Enter | 2분 |
| 리허설 | **녹화 켜기(Win+Alt+R)** → 첫 물품 놓기·옮기기·치우기 → 안내가 나오면 상세 화면 캡처(Win+Shift+S) → 녹화 끄기 | 5분 |
| 초기화 | 보관대를 비우고 웹 화면의 **시연 초기화** → Enter → Pi 비밀번호 입력 | 1분 |
| 실험 A | 등록·이동·치우기 60회. 10개 등록 뒤 캡처 2장 | 40분 |
| AI 이름 확인 | AI가 붙인 이름이 맞으면 `o`, 틀리면 `x` (Enter는 도우미의 추측을 그대로 씀) | 3분 |
| 실험 B | 물품 5개 올리기 → 휴대폰 사진 1장 → 손 20·조명 10·그림자 10회 | 20분 |
| 기능 점검 | Enter 한 번(자동, 물품 1개를 바꿨다가 원래대로 돌려놓음) → 활동 기록 캡처 | 3분 |
| 무인 1시간 | Enter 누르고 자리 비우기(카메라에 사람이 안 보이게) | 60분 |
| 끝 | Pi 비밀번호 한 번 → `끝났습니다`와 zip 파일 위치가 나옴 | 2분 |

**매 시도에서 할 일**: 안내대로 행동 → 손을 화면 밖으로 → 창 ②를 한 번 클릭 → Enter. 결과는 자동으로 판정·기록된다.

**결과가 ‘다름’으로 나오면**: 시스템이 실제로 틀린 것이므로 그대로 둔다. 창 ②의 도움말대로 물건 상태만 맞추고 Enter.

**내가 실수했을 때** (Enter 대신 입력):

| 키 | 언제 |
|---|---|
| `s` | 행동하기 **전에** 이번 시도를 건너뛸 때 |
| `u` | **방금 시도**를 내가 잘못했을 때(다른 물건, 손이 남음, Enter를 너무 빨리 누름). 기록을 지우고 다시 묻는다 |
| `q` | 오늘은 여기서 끝낼 때. 지금까지 결과로 zip을 만든다 |

**중간에 끊기면**(노트북 절전, 터널 끊김): 창 ①을 다시 연 뒤 창 ②에서 `python scripts\experiments\run_experiment.py --resume paper-run-날짜` — 끝난 것은 건너뛰고 이어서 한다.

## 4. 끝나면

1. 평소대로 종료: 창 ①(Pi)에서 `sudo shutdown -h now` → 초록 LED 점멸이 끝나면 전원 분리 → 핫스팟 끄기.
2. **Claude에게 보낼 것**: 창 ②에 표시된 `paper-run-날짜.zip` 1개, 캡처 3–4장, 실험 장면 사진 1장. 첨부가 안 될 만큼 크면 구글 드라이브에 올리고 파일 이름을 알려 준다.
3. 리허설 녹화(노트북 `동영상\캡처` 폴더)는 **시연 백업 영상**이므로 노트북에 남겨 둔다.

## 궁금할 때만 — 측정값은 어떻게 노트북으로 오나

따로 옮길 필요가 없다. 도우미가 관리자 화면과 같은 정보를 SSH 터널로 **읽기만** 해서 처음부터 노트북 폴더에 저장한다. Pi 안에서만 생기는 CPU·온도 기록 하나는 끝날 때 도우미가 가져온다(그래서 Pi 비밀번호를 묻는다). 가져오지 못하면 창 ②에 붙여 넣을 명령 두 줄을 알려 준다. Pi를 바꾸지 않으므로 **측정한 버전이 그대로 시연 버전**이다.
